# AI Usage Statement

## AI Assistance

Artificial Intelligence tools were used as a development aid during this project.

AI assistance was used for:

- Understanding project requirements.
- Reviewing code quality.
- Improving documentation.
- Generating draft explanations.
- Identifying best practices for Node.js and Express.js.

All code was reviewed, modified, tested, and validated before being included in the final project.

The project architecture, implementation decisions, testing, debugging, deployment, and final verification were completed by the developer.
